Robort Scouting App Documentation

This documentation explains the JSON configuration used by your FRC scouting app Robort. The configuration file defines how the UI is built for the field, teleop, additional actions, and endgame phases. Each section below details the meaning of each parameter (excluding any game-specific custom attributes).

JSON Schema Overview

The JSON configuration file contains two main parts:

  • fieldImage – A string path or URL to the background field image.
  • buttonPositions – An object containing configurations for the various UI buttons. This includes:
    • field – Positions for field buttons, driver station buttons, and note buttons.
    • teleop – Configurations for teleoperated mode buttons.
    • additionalActions – Extra action buttons used during teleop.
    • endgame – Configurations for endgame buttons.
    • endgameOutcome – Outcome buttons for endgame results.
    • addtop – A numeric offset to adjust the vertical placement of buttons.
  • jsonAttributes – Maps keys (such as match number, team number, and various action arrays) used internally by the app.

Field Configuration

The field object under buttonPositions controls the layout for elements that appear on the field. Each position includes:

  • id: The HTML element identifier.
  • top and left: CSS positioning values determining the button’s location.
  • hide (optional): If set to true, the button is hidden.
  • name (optional): The text label displayed on the button.

The configurations for driver stations and note buttons follow similar properties, with note buttons typically including a name property as their label.

Teleop Configuration

The teleop section defines the buttons used during the teleoperated phase. Each teleop button includes:

  • id: The HTML element identifier.
  • top, left, width, and height: Values that control the button’s position and size.
  • name: The label text shown on the button.
  • color: The background color used for visual differentiation.
  • size: A style indicator (for example, "large" or "medium") that affects font size and padding.
  • actionType: The type of action (e.g., "score" or "pickup").

Additional Actions

The additionalActions section allows you to specify extra buttons for teleop. Their properties mirror those of the teleop buttons, including position, size, and styling attributes.

Endgame Configuration

The endgame section defines the buttons available during the endgame phase. Each button here includes:

  • id: The HTML element identifier.
  • top, left, width, and height: Values that control the button’s position and size.
  • name: The label text shown on the button.
  • color and size: Styling options for the button.

The endgameOutcome subsection further specifies buttons that capture the outcome of an endgame action (for example, "Park" or "Hang Deep").

JSON Attributes Mapping

The jsonAttributes object maps the internal keys used by your app to the corresponding values in the JSON file. This mapping includes:

  • matchNumber – The match number.
  • teamNumber – The team number.
  • scoutingData – The overall scouting data object.
  • teleopActions – An array of teleop actions.
  • endgameActions – An array of endgame actions.
  • notes – Collected notes.
